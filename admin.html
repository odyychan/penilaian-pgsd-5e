1 Cara Menghubungkan Google Sheets:
  1. Buka file Google Sheets lembar penilaian Anda.
  2. Klik tombol Bagikan (Share) di pojok kanan atas.
  3. Masukkan Email Layanan di atas dengan izin akses Editor.
  4. Salin link spreadsheet dari browser dan tempel pada kolom di bawah.
2 Cara Menghubungkan Google Drive:
  1. Buka Google Drive dan siapkan folder penyimpanan.
  2. Klik kanan folder $\rightarrow$ pilih Bagikan (Share).
  3. Masukkan Email Layanan di atas dengan izin akses Editor.
  4. Salin link folder dari browser dan tempel pada kolom Google Drive di bawah.

Skrip Mini 30-Baris Universal

Pasang 1 kali saja di Google Spreadsheet. Tidak perlu diubah/dideploy ulang lagi.

📋 Cara Pemasangan (Hanya 1 Menit):

  1. Buka file Google Spreadsheet Dosen Anda.
  2. Klik menu Extensions (Ekstensi) > Apps Script.
  3. Hapus semua teks di sana, lalu tempelkan kode 30 baris di bawah ini.
  4. Klik tombol biru Deploy > New deployment > Select type: Web App.
  5. Set Execute as: Me dan Who has access: Anyone, lalu klik Deploy.
  6. Salin Web App URL yang dihasilkan dan tempelkan di kotak setelan admin ini.
